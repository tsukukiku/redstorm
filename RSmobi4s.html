红色风暴

R E D   S T O R M
------
目标：在未知地图（战争迷雾）中侦察、建设基地、采集矿石、训练军队，消灭敌人全部建筑与部队，或用工程师占领敌方关键建筑。

流程：发电厂 → 兵营 / 矿石精炼厂（自带采矿车）→ 战车工厂 → 哨戒炮 / 磁暴线圈防家 → 组建装甲集群决战。
国家加成：十国各有专属加成，在大厅中选择。

电脑操作：
· 左键点击/框选：选择部队　· 右键：移动 / 攻击 / 设集结点
· 右键点击敌方建筑 + 选中工程师 = 占领（工程师牺牲）
· 侧栏点击生产；建筑就绪后再点一次进入放置　右键侧栏项：取消退款
· WASD/方向键/屏幕边缘：移动视角（选中部队时 S=停止）
· 小地图：左键跳转，右键下令　· Ctrl+数字 编队　· 空格 跳到警报　· Enter 聊天　· Esc 取消/菜单　· M 静音

📱 手机版操作：
· 主页选择「手机版」后开战会自动尝试全屏并锁定横屏（需允许）
· 单指点自己的士兵=选中；空地拖动=框选；双指拖动=移动视角
· 选中后：点敌人=攻击，点空地=移动；底部按钮：全选 / 攻击模式 / 停止
· 屏幕右缘向左滑=展开/收起侧栏（生产列表+小地图）
· 右下角 🗺 按钮=悬浮小地图，点按跳转视角，可拖动
· 建筑就绪后点侧栏项 → 拖动绿色区域选位 → 点 ✓ 放置 / ✕ 取消
· 手机上再点正在生产的侧栏项 = 取消一个并退款

电力：耗电＞发电时生产减速、磁暴线圈失效，多造发电厂！
兵种克制：机枪克步兵、坦克炮克车辆/建筑、火箭克重甲、磁暴克一切但吃电。
目標：霧に覆われたマップで偵察・基地建設・採掘・部隊編成を行い、敵の全建物と部隊を破壊するか、工兵で重要建物を占拠する。

流れ：発電所 → 兵舎／精製所（採掘車付き）→ 戦車工場 → 哨戒砲／テスラコイルで防衛 → 戦車部隊で総攻撃。
国家ボーナス：10カ国それぞれ固有のボーナス。

PC操作：
· 左クリック／ドラッグ：選択　· 右クリック：移動／攻撃／ランリー
· 工兵選択＋敵建物を右クリック＝占拠（工兵は消失）
· サイドバーで生産；完成後もう一度クリックで配置　右クリックで取消返金
· WASD／方向キー／画面端：視点移動（選択時 S=停止）
· ミニマップ：左=移動、右=命令　· Ctrl+数字：部隊　· Space：警報へ　· Enter：チャット　· Esc：取消　· M：消音

📱 スマホ操作：
· ホームで「スマホ」を選ぶと開戦時に全画面＋横画面ロックを試みる
· 自軍ユニットをタップ=選択；空き地をドラッグ=範囲選択；2本指ドラッグ=視点移動
· 選択後：敵タップ=攻撃、空き地タップ=移動；下部ボタン：全選択／攻撃／停止
· 画面右端から左スワイプ=サイドバー開閉（生産＋ミニマップ）
· 右下 🗺 =浮遊ミニマップ、タップでジャンプ
· 建築完成後サイドバー項目をタップ → 緑エリアをドラッグ → ✓で配置／✕で取消

電力：消費＞発電すると生産減速・テスラ無効。
相性：機銃＞歩兵、戦車砲＞車両、ロケット＞建物、テスラ＞全て（要電力）。
Goal: Scout the fogged map, build a base, mine ore, raise an army — destroy every enemy structure & unit, or capture key buildings with Engineers.

Flow: Power Plant → Barracks / Refinery → War Factory → Sentry Guns / Tesla Coils → armor push.
Nations: 10 nations, each with a unique bonus.

PC Controls: Left-click/drag select · Right-click move/attack/rally · Engineer onto enemy building = capture · Click sidebar to queue (click READY building again to place) · WASD/arrows/edges pan · Minimap L/R click · Ctrl+# groups · Space alert · Enter chat · Esc cancel · M mute.

📱 Mobile Controls:
· Pick "Phone" on home; game start tries fullscreen + landscape lock
· Tap own unit = select · Drag on empty ground = box select · Two-finger drag = pan
· With selection: tap enemy = attack, tap ground = move; bottom bar: All / Attack / Stop
· Swipe left from right edge = toggle sidebar (production + minimap)
· Bottom-right 🗺 = floating minimap, tap to jump
· Tap READY building in sidebar → drag green area → ✓ place / ✕ cancel

Power: Low power slows production and disables Tesla Coils.
Counters: MG>infantry, cannon>vehicles, rockets>buildings, tesla>all (needs power).
